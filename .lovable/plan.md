# HouseProvider.in — Phase 1 implementation plan

Build a fresh plum-and-peach identity with editorial typography, spacious layouts, original architectural imagery and restrained motion. Replace the previous HouseProvider presentation, records, and images rather than migrating them.

Create a functional first journey: arrive on the photographic homepage, search by location, intent, property type and budget, review filtered results and open a detailed property page. Add responsive desktop and mobile navigation, helpful empty states and clear labels identifying fictional listings. Keep future capabilities visible only as honest coming-later context, not simulated interactions.

Technical approach: retain the supplied TanStack Start runtime; create new typed listing records and pure filter logic; keep reusable search and property presentation separate from routes; use semantic design tokens and route-specific metadata. Verify the journey with desktop/mobile browser checks, form submissions and diagnostics. Defer accounts, AI, verification, maps, 3D, contact, owner flows and payments.
